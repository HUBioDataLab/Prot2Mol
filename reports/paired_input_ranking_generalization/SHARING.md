# Grouped ranking study

Start with [the 34 answers](answers.md). The other documents and tables contain the supporting evidence and unfinished-work inventory.

This package describes an existing study through abstract queries, candidates, groups, labels and experimental settings. Input-specific meanings are undisclosed. It does not assign a different application to the original experiments.

The shared package retains:

- All 34 question assessments and all 70 experiment dispositions.
- The 23 completed fits and all 345 epoch records, with measured values unchanged.
- 1,420,985 numeric, boolean or null evidence fields, including repeated intermediate snapshots.
- The reported uncertainty, coverage, optimization limits and incomplete results.

Original run names, collection names, input-specific field descriptions, source hashes, source locations and infrastructure identifiers are excluded or replaced with anonymous references. The numeric register withholds 1,159 fields containing absolute times or process, account and original collection identifiers. These are identifying metadata, rather than performance measurements. The original audit mapping is maintained separately and is not included here.

Model aliases are described in [the model catalog](measurements/model_catalog.csv). Record IDs refer to [the evidence index](measurements/evidence_index.json). Input-specific checks use labels F01–F04; their meanings are intentionally withheld. Counts of records in anonymous collections and input categories remain unchanged.

The [verification receipt](verification.json) records comparison against the saved originals. The [checksums](report_checksums.json) cover only shared files. Archive entry dates are standardized, and archive comments, source filenames and extra metadata are omitted.

Share the standalone package. The surrounding workspace, source history and authoring files are not part of this anonymized export. Exact numerical results remain potentially matchable to another copy; no claim of universal unlinkability or guaranteed classifier behavior is made.
